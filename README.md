# HIMATIF Samanvaya

Website profil dan ruang informasi HIMATIF Samanvaya.

## Struktur

- `pages/beranda.html` - halaman beranda
- `pages/` - halaman anggota, divisi, berita, kegiatan, dan tentang
- `assets/images/` - aset foto dan ilustrasi
- `assets/icons/` - ikon tambahan
- `assets/logo/` - logo organisasi
- `css/style.css` - gaya visual bersama
- `js/main.js` - navigasi, menu mobile, dan animasi reveal
- `js/anggota.js` - filter anggota
- `js/berita.js` - filter berita

## Menjalankan

Website ini tidak membutuhkan proses build. Buka `pages/beranda.html` langsung di browser atau gunakan ekstensi Live Server di VS Code.

## Catatan

Homepage sudah memakai aset visual berbasis CSS sebagai placeholder. Aset asli bisa dimasukkan ke folder `assets/` dan komponen halaman dapat dikembangkan dari pola yang sudah tersedia.
